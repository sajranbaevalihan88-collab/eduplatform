EduPlatform AI: интерактивная образовательная платформа
Проект для StudEXPO 2026, секция Программирование

1. Что это
Веб платформа, где учитель собирает урок как конструктор: тексты, презентации, тесты с автопроверкой, файлы и интерактивная доска 2D и 3D. Всё в одном месте. Ученик открывает урок и проходит его онлайн: читает, смотрит, решает тесты, пишет и запускает код прямо в браузере — с живым терминалом, как в настоящем Python.

2. Какую проблему решает
Учителям информатики и других предметов приходится жонглировать 4–5 сервисами: конструктор уроков отдельно, тесты отдельно, среда для кода отдельно, доска отдельно. EduPlatform AI соединяет всё в одном окне. Урок создаётся за минуты и сразу доступен ученикам. Викторину для игры класс собирает прямо в профиле и тут же играет на интерактивной доске.

3. Основные возможности
3.1. Уроки из блоков: текст, файлы, презентации, тесты, код, доска, видео. Порядок меняется перетаскиванием.
3.2. Презентации как PowerPoint: 14 фигур, таблицы, диаграммы, переходы, анимации, слайдшоу.
3.3. Импорт pptx и pdf: готовая презентация превращается в слайды 1 в 1. Геометрия, шрифты, цвета, таблицы с объединёнными ячейками, диаграммы, переходы, EMF картинки.
3.4. Запуск кода 4 языков: Python и JavaScript — живой интерактивный терминал по WebSocket (программа спрашивает input() — отвечаешь прямо в терминале, как в online-python), плюс надёжный HTTP-режим. HTML и CSS — сразу в preview. Свой редактор на Monaco, до 99 файлов, общий доступ по ссылке.
3.5. Тесты с автопроверкой и античитом: один или несколько вариантов, текст, верно или неверно, проходной балл. Прохождение — по одному вопросу: выбрал ответ — вопрос сменился сам, кнопок Назад/Дальше нет. На каждый вопрос — таймер (настраивается, 0 — без лимита): время вышло — авто-дальше, скриншотить и списывать некогда. Озвучка читает только текущий вопрос.
3.5.1. Настоящий ИИ-генератор тестов: Google Gemini 2.5-flash. Учитель пишет указание своими словами («тест на тему Атомы, 3 вопроса с одним ответом») — нейросеть делает вопросы нужных типов на нужную тему, до 40 штук за раз. Валидация типов и ответов на сервере. Честный бейдж в интерфейсе: зелёный «сгенерировано нейросетью» или жёлтый «офлайн-режим». Без ключа работает резервный офлайн-генератор. API: POST /api/tests/generate/ {lesson_id?, text?, count?, prompt?} -> {questions, source}.
3.6. Доска 2D и 3D: куб, сфера, орбита, векторы для геометрии, физики, астрономии.
3.7. Три языка интерфейса: RU, EN, KG. Тёмная тема, режим для слабовидящих, режим проектора для доски.
3.8. Заметки с таймером и напоминанием (живут в профиле): заголовок + текст + дата remind_at + таймер обратного отсчёта ЧАСЫ/МИН/СЕКУНДЫ + живой счётчик «введено N из M» для input(). Напоминание — Notification + MP3-рингтон + озвучка. 3 рингтона (Стандарт/Волна/Тревога) — настоящие MP3, громкость настраивается. API: /api/notes/.
3.9. Режим для незрячих и слабовидящих: совместимость со скринридерами (NVDA/JAWS/VoiceOver/TalkBack) — семантика, skip-link, aria-live, role=timer, фокус 3px, Tab/Enter/Esc без мыши. Своя озвучка по предложениям: клик/тап/Enter по предложению (SpeakableText), скорость 0.5–2x, громкость, голоса RU/KG/EN с автовыбором. poor-vision: контраст, шрифт 100–200%, без анимаций.
3.10. Мини-Word: свой редактор документов — жирный/курсив/подчёркнутый/зачёркнутый, заголовки H1–H3, списки, выравнивание, размер/цвет шрифта, маркер, ссылки, картинки (размер+положение), таблицы (выбор строк×столбцов, +/-), печать, озвучка, счёт слов. Постраничный вид как в Word: направляющие листов, счётчик «Стр. X из Y», кнопка разрыва страницы (в .docx — настоящий разрыв, обратно — тоже). Листы А5/А4/А3, полный экран (Esc — выход), черновики не теряются. Импорт .docx до 20МБ (python-docx: заголовки, списки, таблицы, bold/italic + mammoth-фолбэк офлайн), экспорт в .docx в 1 клик, хранение в БД. API: /api/word-docs/, /api/word-docs/import/, /api/word-docs/export/.
3.11. Игры и практика: хаб /games + режим «Проектор» для интерактивной доски. Аркан тартыш: 2 команды тянут канат ответами — отсчёт 3-2-1, кольцо таймера, живой канат с тряской, очки за скорость + комбо, финал с конфетти, кыргызская арена (Көк/Кызыл, талисманы). Вопросы: готовые Даяр-темы (Математика, Информатика, Кыргыз тили), свои и публичные викторины; конструктор — в профиле («Мои игры», кнопка «Играть» открывает бой сразу). Античит: ответы проверяет сервер (POST /api/tests/{id}/answer/), после ответа — сразу следующий вопрос без кнопки «Дальше». Спринт печати 15/30/60 как Monkeytype: WPM, точность, наборы RU/KG/EN/свои/из урока, режим «Побей 71», клики клавиш. Быстрые пары: мемори «термин — определение». Звуки — настоящие MP3 (10 штук) с WebAudio-фолбэком, рекорды локально.
3.12. Профиль — центр учителя: мои уроки/презентации/тесты/черновики + Заметки + Мои игры (конструктор викторин с ИИ и кнопкой «Играть в Аркан»).

4. Что под капотом интересного
4.1. Свой парсер PowerPoint на 600 строк: понимает полупрозрачные заливки, пунктирные линии, объединённые ячейки, текст из SmartArt, данные из диаграмм превращает в таблицу.
4.2. Честная песочница + живой ввод: каждый запуск кода в отдельном каталоге, без доступа к секретам сервера. Запрещены eval, subprocess, сокеты. Интерактивный ввод — по WebSocket через daphne (на обычном runserver его нет — проверено). Вредоносный код ученика ничего не сломает.
4.3. Настоящий ИИ, а не имитация: генерация вопросов — Google Gemini 2.5-flash по свободному указанию учителя, с серверной валидацией и честным бейджем источника. Без ключа — прозрачный офлайн-режим.
4.4. Деплой одной командой: Docker, настоящий PostgreSQL. Это рабочая система, а не макет.
4.5. Проверки как в больших компаниях: матрица из 10 презентаций, скриншот тесты слайдов в браузере без участия человека, чистый TypeScript.
4.6. Цифры для плаката: 9 приложений Django, 27+ таблиц, 14 групп API, 14 фигур, 99 файлов в редакторе, 3 языка интерфейса, 4 языка кода, до 40 вопросов за одну ИИ-генерацию, 10 MP3-звуков.
4.7. История с шрифтом: слайды часто набраны редким шрифтом MiSans. Сайт сам подгружает его с кириллицей, поэтому всё выглядит как в оригинале даже на чужом компьютере.
4.8. Скорость: vendor разбит на чанки без хэшей в именах, тяжёлые редакторы (Word, LessonBuilder, Monaco) грузятся лениво — стартовая страница весит в разы меньше.
