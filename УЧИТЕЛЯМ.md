# EduPlatform — инструкция для учителей

EduPlatform — это веб-платформа для уроков: материалы, презентации, тесты, классы, игры-практика и редактор кода — в одном окне, на любом устройстве, включая слабые компьютеры.

---

## 1. Начало работы

1. Откройте сайт и нажмите **«Создать аккаунт»**.
2. Заполните имя, email, пароль и обязательно выберите роль **«Учитель»**.
3. После входа вы попадаете на **Дашборд** — отсюда доступен весь функционал через меню слева.

> Роль выбирается один раз при регистрации. Если случайно создали аккаунт как ученик — создайте новый с ролью «Учитель».

---

## 2. Классы — ваш главный инструмент

**Создать класс:**
1. Меню **«Классы»** → **«Создать класс»** → укажите название (например, «8А — информатика»).
2. Платформа сгенерирует **код приглашения** (например, `A7K2P9`). Покажите его ученикам — они вводят код у себя и попадают в класс.
3. Код можно в любой момент скопировать из карточки класса.

**Внутри класса:**
- **Ученики** — список участников, кого можно удалить из класса.
- **Журнал** — оценки по тестам: поиск ученика, сортировка по успеваемости, цветные средние баллы (зелёный/жёлтый/красный), Enter — переход к следующему ученику.
- **Отчёт по классу** — одна кнопка, и вы получаете краткую сводку: кто лидер, кто отстаёт, что стоит повторить. Работает офлайн-статистикой даже без интернета-сервисов.
- **Объявления** — короткие сообщения классу (домашка, changes в расписании).
- **Комментарии** — переписка по классу.

**Платные занятия (по желанию):**
1. Включите платный режим в классе, укажите цену и реквизиты.
2. Загрузите свой QR-код банка (скриншот) — ученики увидят его прямо в классе.
3. Ученик отправляет скриншот чека → у вас появляется очередь на подтверждение → «Одобрить» или «Отклонить». Доступ открывается автоматически.

---

## 3. Уроки

1. **«Уроки»** → **«Создать урок»**: название, предмет, класс.
2. Урок собирается из **блоков**: текст, видео (YouTube-ссылка превращается в плеер), файлы, картинки, **встроенные тесты** — мини-проверка прямо внутри урока.
3. Во встроенный тест можно **сразу наделать вопросов автоматически**: нажмите «Создать вопросы автоматически», напишите тему (например, «циклы for в Python, 5 вопросов») — вопросы появятся в списке, поправьте и сохраните.
4. Урок можно сделать **публичным** — тогда его видно даже без вступления в класс (удобно для ссылок родителям).

Ученик открывает урок, читает/смотрит, проходит встроенные проверки — вы видите результаты в журнале.

---

## 4. Презентации

- **«Презентации»** → создать → добавляйте слайды: заголовок, текст, картинка, видео.
- Режим **показа** — полноэкранный, листаете стрелками, как в PowerPoint, только ничего не надо скачивать.
- Готовую презентацию можно приложить к уроку или показать классу прямо с сайта.

---

## 5. Тесты

1. **«Тесты»** → **«Новый тест»**.
2. Два пути:
   - **«Создать сам»** — полная форма: вопрос, варианты, отметка правильного, баллы, объяснение ошибки.
   - **«Создать автоматически»** — напишите тему и пожелания («только Верно/Неверно про циклы»), вопросы сгенерируются, вы их правите. Работает и с внешним генератором, и в офлайн-режиме из вашего текста (минимум 100 символов).
3. До 40 вопросов, несколько типов вопросов, баллы за каждый.
4. Тест назначается классу, результаты — в журнале класса.

---

## 6. Игры-практика

Игры можно открывать как готовые наборы вопросов или **из своего урока**:

| Игра | Что тренирует |
|---|---|
| **Аркан** | Командная игра «перетяни канат» — 2 команды отвечают на вопросы |
| **Спринт** | Быстрые ответы на время |
| **Виселица / Найди слово** | Словарные слова по теме (можно подобрать автоматически или взять из урока) |
| **Память, Цвета** | Разминка и внимание |
| **Ферма** | Пошаговые задачи с запуском настоящего кода |

## 7. Редактор кода (мини VS Code)

Для уроков информатики: **«Редактор кода»**.

- Файлы проекта: Python, JavaScript, HTML+CSS — с подсветкой и автодополнением.
- **Run ▶** запускает код; для HTML — живое превью прямо рядом с кодом, перегородку можно двигать, страницу можно открыть в новой вкладке.
- Проекты: включите режим «Проект», при необходимости укажите `requirements` (например, `django pygame`) — код выполняется на сервере в песочнице.
- Есть **SQL-лаборатория** для практики баз данных и объяснение ошибок кода простыми словами.

---

## 8. Доска, Word, заметки

- **Доска 2D/3D** — рисуйте и объясняйте прямо на занятии.
- **Word** — простой текстовый редактор: конспекты, раздатки без Word-файлов на флешке.
- **Заметки** — личные записи, всегда под рукой.

---

## 9. Доступность и языки

В шапке сайта: переключение **RU / KY**, тема (светлая/тёмная), **Доступность** — озвучка текста вслух, крупный шрифт. Раздел «Путеводитель» (/guide) — пошаговый озвученный тур по платформе для незрячих пользователей.

---

## 10. Частые вопросы

**Ученик не видит урок?** — Урок приватный, а ученик не в классе. Дайте ему код приглашения или сделайте урок публичным.

**Тест не открывается ученику?** — Проверьте, что тест назначен его классу, а в платном классе доступ подтверждён.

**Код генерации вопросов не работает?** — Платформа честно переключается в офлайн-режим и собирает вопросы из вашего текста — просто вставьте текст урока.

**Где смотреть оценки?** — Классы → ваш класс → вкладка «Журнал».
