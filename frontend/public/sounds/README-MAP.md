# Карта звуков (кое-что меняется — перегенерировать: `python scripts/gen_ui_sounds.py`)

Все mp3 здесь — ОДНА звуковая семья, синтезированы одним движком
(негармонические колокольчики + Karplus-Strong + студийная цепочка).
**Исключение: `arkan-*.mp3`** — этно-набор Аркан тартыш (комуз + барабан), отдельная тема.

| Файл | Где звучит | Момент |
|---|---|---|
| `ui-success.mp3` | Любой тост «успешно» (сохранил урок/тест/задание) | `UIContext` |
| `ui-error.mp3` | Любой тост «ошибка» | `UIContext` |
| `ui-notify.mp3` | Тест не пройден (нейтральный сигнал) | `TestTake` |
| `ui-win.mp3` | **Тест пройден** — фанфара | `TestTake` |
| `ui-start.mp3` | Первый ответ в попытке теста — «поехали!» | `TestTake` |
| `ui-save.mp3` | Заметка сохранена | `Notes` |
| `ui-pop.mp3` | Резерв (пузырь для панелей) | — |
| `correct.mp3` | Игры: правильный ответ (фолбэк движка) | `sound.ts` |
| `wrong.mp3` | Игры: неправильный ответ (фолбэк движка) | `sound.ts` |
| `win.mp3` | Игры: победа (фолбэк движка) | `sound.ts` |
| `go.mp3` | Игры: «старт!» (фолбэк движка) | `sound.ts` |
| `tick.mp3` | Игры: тик таймера (фолбэк движка) | `sound.ts` |
| `arkan-correct/go/tick/win/wrong .mp3` | Аркан тартыш — этно-набор, НЕ трогать | `Arkan` |
| `standard.mp3` | Рингтон таймера заметок «Обычный» (на выбор) | `Notes` |
| `wave.mp3` | Рингтон таймера заметок «Волна» (на выбор) | `Notes` |
| `alarm.mp3` | Рингтон таймера заметок «Сигнал» (на выбор) | `Notes` |
| `notify.mp3` | Рингтон напоминания по умолчанию | `Notes` |
| `type.mp3` | Спринт печати — клавиша | `Sprint` |

Игры (ВислоСлов, Память, Цвета, Пары, Фермер и т.д.) играют через WebAudio-движок
`sfx()` — у них звуки синтезируются в момент нажатия и mp3-файлов не читают;
mp3 выше нужны движку `sound.ts` (Аркан, заметки, спринт) как рабочий набор.

Мьют: кнопка 🔊/🔇 в шапке глушит **всё** (ключ `edu-sfx-mute`).
